# Simple Interest Calculator

Final project for Getting Started with Git and GitHub.

A Bash calculator that computes simple interest from a principal amount, annual
interest rate (as a percentage), and time period in years.

## Usage

```bash
bash simple-interest.sh
```

Enter the principal, annual percentage rate, and number of years when prompted.
The formula is `interest = principal × rate × time / 100`.
For example, principal 1000, rate 5, and time 2 produces interest 100.00.
